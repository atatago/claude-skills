# コーディング規約(<言語>)

コードを書くときだけ読む細則。法律の一部として扱う(設計の哲学より優先)。

**ツールで強制しているものは書かない。** フォーマット・命名・未使用の変数など、フォーマッタ・リンター・型チェックが止めるものは、どのツールが何を確かめているかを1行で書くだけにする。ここに書くのは、ツールでは確かめられない決めごとだけ。

## 1. ツールで確かめていること

- 〔仕組み: <ツール名>〕<何を確かめているか>

## 2. 構成

- フォルダごとの役割と、依存してよい向き(機械で確かめているなら〔仕組み〕を付ける)

## 3. 書き方

- エラー処理の方針
- 外部サービス・時刻・乱数などの差し替え方(設計の哲学 3 の具体化)
- コメント・ドキュメントの書き方と言語

## 4. テスト

- 何をどのテストで確かめるか

## 改正履歴

- YYYY-MM-DD 初版
