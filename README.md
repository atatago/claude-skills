# claude-skills

Claude Code / Claude.ai で使える Agent Skills。

## governance-docs

AI と進めるプロジェクトの判断基準を、**憲法・法律・哲学・細則**の階層で文書にし、あとから振り返って見直すためのスキル。

- **憲法**: 何があっても守る原則(5〜8条)
- **法律**: 憲法に反しない範囲の具体的なルール。CI・テストなどの仕組みで確かめている条文には〔仕組み: …〕の印を付ける
- **哲学**: 決まりがない場面の判断の拠り所
- **細則**: 毎回は読まない詳しい内容(ライセンスの台帳など)

考え方の中心は次の3つ。

1. 文書は内側から(AI が理解して判断する)、仕組みは外側から(CI やテストで止める)効かせ、使い分ける。外側で止めるのは「結果として許されない状態」だけにする
2. ルールには、足した理由ときっかけを残す。理由があれば、効いているかを確かめられ、要らなくなったら外せる
3. 文書だけのルールが繰り返し破られたら、注意書きを足すより先に、仕組みで止める

見直しでは、レビューの指摘や失敗を「ルールがあって防げた/ルールがあったのに破られた/ルールがなかった」に分け、指摘の種類ごとにルールを足した前後で比べる。

背景: [コード生成ルールとしての憲法と哲学(Zenn)](https://zenn.dev/atatago/articles/cde7fa8f05b1f2)

## インストール

### Claude Code

```
/plugin marketplace add atatago/claude-skills
/plugin install governance@atatago-skills
```

### Claude.ai

`plugins/governance/skills/governance-docs` フォルダを ZIP にして、Settings > Skills の「Upload skill」から取り込む。

## 使い方

- 新しいプロジェクトで「ガバナンス文書を作って」と頼む
- 既存のプロジェクトで「ガバナンス文書を振り返って見直して」と頼む(修正の前に方針を示し、確認してから直す)
